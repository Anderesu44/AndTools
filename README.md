# Andev tools
> Andev Tools is a collection of utilities for Python development
> <br>_V: 1.6.1_

## Install

### Requierements

- **Python 3.13+**

## Install Step

1. Clone Repository
   ```bash
   git clone https://github.com/anderesu44/andtools.git
   ```
2. enter in directory
   ```bash
   cd andtools
   ```
3. instalar dependencias
   ```bash
   pip3 install -r requierements.txt
   ```
4. Empaquetar
   ```bash
   python3 -m build
   ```
5. installar
   ```bash
   pip3 install dist/andtools-1.6.1-py3-none-any.whl
   ```
